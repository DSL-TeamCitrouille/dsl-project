# Lessons Learned

Through this project, we learned that Langium offers many possibilities and is a powerful framework for creating a domain-specific language (DSL). However, discovering Langium for the first time can be quite challenging. It requires time to understand its core concepts, recommended practices, and overall architecture. Becoming comfortable with grammar definitions and validation rules required tries and errors, especially when translating theoretical concepts into a practical implementation.

Developing the different language variants was a crucial step in refining our vision of the DSL. This process revealed that some features needed further development, while others had to be simplified or removed entirely because they added unnecessary complexity. Iterating on the language design was essential, and we continuously adjusted it throughout the project to better align with our goals, as well as with what was feasible given our current knowledge and skills.

The implementation phase, using HTML and TypeScript, was also demanding. Designing the user interface and writing the necessary scripts to make the game functional required a lot of effort. Ensuring proper separation of concerns between HTML structure and TypeScript logic, as well as identifying and organizing the different classes and components, took time but ultimately improved the clarity and maintainability of the project.

Working with an LLM was another valuable learning experience. Integrating it into the project and interacting with it demonstrated its effectiveness, particularly in a game context where it can easily outperform a human player. At the same time, using an LLM during development showed us that it is most effective as a supportive assistant, helping with ideas and debugging rather than as a final decision-maker.

Beyond the technical aspects, this project highlighted the importance of iteration and continuous feedback when collaborating in a team. Regular discussion and refinement were key to aligning our ideas and progressing effectively.

Overall, this project was comprehensive and insightful. It allowed us to explore multiple facets of the DSL ecosystem and deepen our understanding of language design. By the end, we gained a clear and practical understanding of how DSLs are designed, implemented, and used in real-world scenarios.
